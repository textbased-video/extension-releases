# textbased.video for Premiere Pro

Installer downloads for the textbased.video panel for Adobe Premiere Pro.

**Latest:** [textbased.video-premiere.ccx](https://github.com/textbased-video/extension-releases/releases/latest/download/textbased.video-premiere.ccx)

- Premiere Pro on Mac (25.6 or later).
- Install it with the free [aescripts ZXP/UXP Installer](https://aescripts.com/learn/post/zxp-installer), then restart Premiere and open **Window → UXP Plugins → textbased.video**.
- A licence key is needed to activate it. Questions: support@textbased.video
